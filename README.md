## Локальный запуск для ревью

Нужен Python 3.12. Выполните команды в PowerShell из папки проекта.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py --demo
```

Откройте `http://127.0.0.1:5000`. В режиме `--demo` сайт слушает только локальный адрес и создаёт ключ сессии при запуске.

| Задание | Страница | Как устроено |
| --- | --- | --- |
| Среднее №3 | `/` | Статический HTML и собственный `reading.css` |
| Среднее №5 | `/showcase` | Таблица, бейджи и кнопка Bootstrap 5 через CDN |
| Среднее №9 | `/recommendations` | Flask передаёт подборку книг в шаблон Jinja2 |
| Повышенное №3 | `/reading-room` | Вход, сессия и выход в модуле `access.py` |
| Повышенное №7 | Heroku | Для ревью используется локальный запуск Flask |

## Демонстрация на ревью

1. Покажите главную страницу, витрину Bootstrap и подборку рекомендаций.
2. Откройте читальный зал. До входа появится форма с именем и паролем.
3. Войдите как `reader` с паролем `reading-demo`. Затем нажмите «Выйти» и снова откройте читальный зал.

## Вход со своим паролем

Остановите сервер, выполните команду ниже и придумайте отдельный пароль
для учебного сайта. Команда выведет хеш пароля и ключ сессии.

```powershell
.\.venv\Scripts\python.exe -m flask --app main access-values
$env:READING_USER = 'reader'
$env:READING_PASSWORD_HASH = '<значение после READING_PASSWORD_HASH=>'
$env:SECRET_KEY = '<значение после SECRET_KEY=>'
.\.venv\Scripts\python.exe main.py
```

Откройте `/reading-room` и войдите как `reader` с придуманным паролем.
Кнопка «Выйти» завершает сессию. Переменные окружения задаются в терминале
для текущего запуска.
